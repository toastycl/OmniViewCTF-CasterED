# OmniViewCTF - Caster Edition v2.1

Released: **23 October 2026**

v2.1 is a broadcast-polish update focused on Player Cam usability, spectator HUD layout, chat positioning, and larger-team support.

## Highlights

- Frameless Player Cam with team-colored player name
- Smaller centered Player Cam crosshair
- Configurable main spectator `BehindView 0 / 1` toggle
- Improved lower HUD spacing and vertical centering
- Refined spectator bar and timer scale
- Jump Boots presence and remaining charge display when available
- Chat below RED scoreboard
- Kill feed below BLUE scoreboard
- Dedicated `Say:` typing row
- Scoreboards now support more than five players per team
- Internal capacity increased to 16 players per side
- `FK` replaces `FCK`
- Cleaner RED / BLUE headers

Replace the previous v2.0 runtime files with the v2.1 files and restart Unreal Tournament.

Caster Edition still uses manual Start / Stop from:

**Mod -> OmniViewCTF - Caster Edition**
