
# OmniView4CTF
A replacement HUD for streaming UT99 CTF games.  

Check out [OmniView4TDM](https://github.com/W4yland3r/OmniView4TDM) for a (T)DM version.

## Description
OmniView4CTF essentially replaces the standard UT99 HUD with a broadcasting-friendly one for streaming 5v5 CTF 
games, both NW and IG. It shows all the important information in a concise and minimalistic way while also offering
customization options to a degree as well as some automation features.
