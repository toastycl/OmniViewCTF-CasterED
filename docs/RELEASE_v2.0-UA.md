# OmniViewCTF - Caster Edition UA v2.0

Stable Unreal Arena branded edition of OmniViewCTF - Caster Edition v2.0 for Unreal Tournament 99 CTF.

## Highlights

- Separate package: `OmniViewCTF_CasterED_UA`
- Can coexist with the neutral `OmniViewCTF_CasterED` edition
- Unreal Arena logo and branding enabled by default
- Compact CTF scoreboard
- Improved spectator HUD
- Item and powerup timers
- Last Capture tracking
- MVP prediction and MVP Focus
- Player Compare
- Secondary Player Cam
- Floating player names
- Improved chat, kill feed and center-message layout
- Manual Start / Stop; no AutoStart

## Player Cam

Player Cam uses the UT99-compatible tracking implementation. When locked to a remotely viewed player it uses replicated Pawn rotation and does not rely on `RemoteViewPitch`.

## Installation

Copy the release files into the Unreal Tournament `System` folder:

```text
OmniViewCTF_CasterED_UA.u
OmniViewCTF_CasterED_UA.int
OmniViewCTF_CasterED_UA.ini
```

See `README.md` for full installation, configuration, feature and source-build documentation.
